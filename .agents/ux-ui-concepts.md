# UX/UI Concepts

The visual style of SLAY CITY is based on a bright, modern, game-like design with Slay as the emotional center of the product.

The UI should feel energetic, playful, motivational, and safe for children. It should not look like a traditional school platform or boring educational dashboard.

The main visual direction includes:

* Dark background
* Neon pink accents
* Lime green action elements
* Cyan and purple highlights
* Large rounded cards
* Bold typography
* Reward-focused screens
* Character-driven interface

Primary brand colors:

```txt
Neon Pink:  #FF2D8E
Lime Green: #9DFF00
Cyan:       #00F0FF
Purple:     #6A00FF
Black:      #111111
White:      #FFFFFF
```

The main screens for the MVP are:

* Welcome screen
* Onboarding screen
* City map screen
* Mission screen
* Reward screen
* Wardrobe screen
* Parent dashboard
* Admin content screen

The UX must always be simple, mobile-first, and child-friendly. Each screen should have one clear primary action.
