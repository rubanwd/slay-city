# SlayButton

The primary interactive element across SLAY CITY. Supports neon pink, lime green, and ghost variants in three sizes with a built-in loading state.

## Usage

```tsx
import { SlayButton } from "@/components/ui";

<SlayButton variant="pink" size="md" onClick={handlePress}>
  Get Started
</SlayButton>
```

## Variants

Use **pink** for the primary CTA on every screen. Use **green** for positive confirmations (continue, claim). Use **ghost** for secondary or destructive actions.

## Accessibility

- Uses a native `<button>` element — keyboard and screen-reader accessible without any extra wiring.
- `focus-visible` ring colour matches the variant (pink ring for pink variant, etc.) so it's always visible against the dark background.
- `aria-busy` is set to `true` during loading; `aria-disabled` is set when `disabled` or `loading`.
