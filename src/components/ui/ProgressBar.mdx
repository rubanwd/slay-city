# ProgressBar

Displays XP, level, or streak progress. Animates on mount and on value changes using a 600 ms ease-out CSS transition.

## Usage

```tsx
import { ProgressBar } from "@/components/ui";

<ProgressBar
  value={45}
  label="XP"
  labelRight="450 / 1000 XP"
/>
```

## Variants

| Variant | Colour | Use case |
|---------|--------|----------|
| `green` | Lime Green | XP, primary progress |
| `pink`  | Neon Pink  | Health, lives, energy |
| `cyan`  | Cyan       | Streak, time-based progress |

## Accessibility

- Uses `role="progressbar"` with `aria-valuenow`, `aria-valuemin`, and `aria-valuemax`.
- Value is always clamped to `[0, 100]` internally.
